# agentdisco-charts

Chart renderer for AgentDisco discoverability reports (weekly share by Intent, and projected uplift), with platform and competitor marks built in.

```html
<div id="adc1"></div><script src="https://cdn.jsdelivr.net/gh/vincentmcleese/agentdisco-charts@1.1.2/charts.min.js"></script><script>AgentDiscoCharts.render("adc1",{"chart":"losing","weeks":[],"panels":[]})</script>
```
